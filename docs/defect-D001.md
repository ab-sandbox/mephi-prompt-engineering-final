## Результаты проверки

| ID  | Ожидаемый вывод  | Фактический вывод     |

| T06 | `DIGIT\n`        | `LEN\nDIGIT\n`        |
| T15 | `OK\n`           | `LEN\n`               |
| T16 | `CHAR\n`         | `LEN\nCHAR\n`         |

## Причина

В условии проверки длины оператор `<` заменён на `<=`.

В результате пароль длиной ровно 8 единиц UTF-16
ошибочно считается недопустимым.
