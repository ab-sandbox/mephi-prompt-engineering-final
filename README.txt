ВАЛИДАТОР ПАРОЛЯ

Итоговый проект по дисциплине «Промпт-инжиниринг для разработчиков» НИЯУ МИФИ, 2026.

1. НАЗНАЧЕНИЕ

Консольное приложение проверяет пароль на соответствие заданным правилам и выводит результат проверки.

2. ТРЕБОВАНИЯ К СРЕДЕ

Java 17 (JDK).
Проверено на OpenJDK 17.0.21.1.
Внешние зависимости отсутствуют.
Для запуска тестов необходим Bash.

3. СБОРКА

Из корневого каталога проекта:

mkdir -p out
javac --release 17 -encoding UTF-8 -d out src/PasswordValidator.java

4. ЗАПУСК

java -cp out PasswordValidator

Программа считывает одну строку из стандартного ввода.

Допустимый пароль:
- длина от 8 до 16 единиц UTF-16;
- только латинские буквы и цифры;
- минимум одна заглавная латинская буква;
- минимум одна цифра.

Пример успешной проверки:

printf 'Passw0rd\n' | java -cp out PasswordValidator

Результат:
OK

Пример проверки с ошибками:

printf 'ab!\n' | java -cp out PasswordValidator

Результат:
LEN
UPPER
DIGIT
CHAR

Все примеры содержат вымышленные пароли.

5. ТЕСТИРОВАНИЕ

bash tests/run-tests.sh

Тестовый сценарий самостоятельно компилирует программу и сравнивает фактический вывод с ожидаемым.

Финальная регрессия: 20 PASS, 0 FAIL.
Объём реализации: 73 непустые строки без комментариев.
