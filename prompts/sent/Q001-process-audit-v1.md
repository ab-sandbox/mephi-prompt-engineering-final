# Q001 — Независимый аудит карты процесса

## Цель

Провести независимый аудит карты процесса разработки консольного приложения «Валидатор пароля» с использованием LLM.

Необходимо выявить недостатки в организации процесса до начала реализации программы.

## Входные данные

К запросу прилагаются два документа:

1. `requirements-v1.md` — утверждённые требования R01–R11, технические ограничения и критерии завершения C01–C10.
2. `process-map-v1.md` — карта процесса из шести шагов A–F с контрольными точками KT1–KT4.

Рассматривай полные тексты этих документов как единственный источник требований и правил процесса.

## Задача

Проверь:

1. Полноту передачи данных между шагами A–F.
2. Наличие входов, выходов и проверок для каждого шага.
3. Условия переходов через KT1–KT4.
4. Маршруты возврата при обнаружении ошибок.
5. Ограничение на два запроса к LLM для исправления одного дефекта.
6. Полноту фиксации решений разработчика.
7. Возможность выполнения итоговой приёмки по имеющимся артефактам.

## Ограничения

- Не генерируй Java-код.
- Не изменяй функциональные требования R01–R11.
- Не предлагай новые функции приложения.
- Не переписывай карту процесса целиком.
- Не считай отсутствие информации доказательством её наличия.
- Предлагай только минимальные изменения, необходимые для устранения обнаруженных недостатков.

## Формат ответа

Для каждого замечания укажи:

- **ID:** A01, A02 и далее.
- **Место:** шаг или контрольная точка.
- **Проблема:** конкретный пропуск или противоречие.
- **Последствие:** к чему это может привести.
- **Минимальное исправление:** что именно нужно уточнить.

В конце приведи:

- Количество замечаний.
- Перечень критических замечаний.
- Вывод о готовности карты к выполнению.

## Критерии успешности

Аудит считается содержательным, если каждое замечание связано с конкретным элементом карты и сопровождается проверяемым
минимальным исправлением.

## Работа с неопределённостью

Если для оценки недостаточно информации, явно укажи, каких данных не хватает. Не придумывай отсутствующие правила и
решения.
