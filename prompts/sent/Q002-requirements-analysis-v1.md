# Q002 — Анализ требований

## Цель

Проверить полноту, однозначность и проверяемость требований к валидатору пароля.

## Входные данные

Приложенный документ `requirements-v1.md`.

## Задача

Выявить противоречия, неоднозначности и риски реализации требований R01–R11.

## Ограничения

- Не изменять требования самостоятельно.
- Не добавлять новые функции.
- Не генерировать код и тестовые сценарии.
- Соблюдать технические ограничения проекта.

## Формат ответа

Для каждого замечания указать:

- Идентификатор замечания.
- Идентификатор требования.
- Описание проблемы.
- Минимальное предлагаемое уточнение.

Отдельно перечислить требования без замечаний.

## Критерии успешности

Рассмотрены все требования R01–R11. Каждое замечание обосновано.

## Работа с неопределённостью

При недостатке информации явно указать неопределённость, не подменяя её предположениями.
