# Q004 — Реализация программы

## Цель

Реализовать консольный валидатор пароля на Java 17.

## Входные данные

- `requirements-v2.md` — утверждённые требования.
- `scenarios-v1.md` — утверждённые тестовые сценарии.

Приоритет имеют требования v2.

## Задача

Создать Java-программу, реализующую все требования R01–R11 и соответствующую ожидаемому поведению в сценариях T01–T20.

## Ограничения

- Java 17, только стандартная библиотека.
- Один файл `PasswordValidator.java`, без объявления package.
- От 50 до 150 непустых строк кода без учёта комментариев.
- Без Maven, Gradle и внешних зависимостей.
- Без дополнительных функций и интерактивных приглашений.
- Не изменять требования и тестовые сценарии.
- Избегать искусственного увеличения объёма кода.

## Формат ответа

1. Полный исходный код `PasswordValidator.java`.
2. Краткое пояснение технических решений.
3. Команды компиляции и запуска.

## Критерии успешности

Код соответствует R01–R11, техническим ограничениям и ожидаемым результатам T01–T20.

## Работа с неопределённостью

При обнаружении противоречий или недостатка данных явно сообщить об этом. Не изменять требования самостоятельно.

Не утверждать, что компиляция или тестирование выполнены, если фактический запуск не производился.
