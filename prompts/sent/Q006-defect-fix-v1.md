# Q006 — Исправление дефекта D001

## Цель

Локализовать и устранить подтверждённый дефект
консольного валидатора пароля.

## Входные данные

- `requirements-v2.md` — утверждённые требования.
- `scenarios-v1.md` — утверждённые сценарии.
- `PasswordValidator.java` — дефектная версия.
- `defect-D001-before.log` — фактические результаты проверок.

Дефект намеренно внесён разработчиком в учебных целях.

## Задача

Определить причину провала тестовых сценариев
и предложить минимальное локальное исправление.

## Ограничения

- Java 17, только стандартная библиотека.
- Не изменять требования и тестовые сценарии.
- Не добавлять новые функции.
- Не выполнять несвязанный рефакторинг.
- Сохранить существующий формат вывода.
- Сохранить объём программы в пределах 50–150 строк.

## Формат ответа

1. Причина дефекта.
2. Нарушенные требования.
3. Минимальное исправление в формате unified diff.
4. Перечень затронутых тестовых сценариев.
5. Перечень необходимых повторных проверок.

## Критерии успешности

Исправление устраняет причину всех подтверждённых
расхождений и не нарушает ранее корректное поведение.

## Работа с неопределённостью

При недостатке данных явно указать, какие сведения
необходимы для локализации дефекта.

Не утверждать, что исправление прошло тестирование,
если фактическое выполнение не производилось.
