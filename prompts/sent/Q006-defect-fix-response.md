# Q006 — Исправление дефекта D001

## 1. Причина дефекта

В `validate()` условие проверки длины записано как:

```java
if (len <= 8 || len > 16) {
```

Это неверно: по R02 допустима длина **от 8 до 16 включительно**. Условие `len <= 8` срабатывает при длине **8**, что ошибочно даёт `LEN` для корректного пароля из 8 символов. При этом для длины 9–16 проверка работает правильно, для 7 и меньше — тоже (даёт `LEN`), для 17 и больше — правильно.

Иными словами, дефект — **сдвиг нижней границы на единицу**: вместо `len < 8` используется `len <= 8`. Это единственное изменение, отличающее дефектную версию от корректной.

Подтверждение по логу:

- **T01** (`Passw0rd`, 8 симв.): ожидалось `OK`, получено `LEN` — сработало `len <= 8`.
- **T06** (`Password`, 8 симв.): ожидалось `DIGIT`, получено `LEN` + `DIGIT` — лишний `LEN`.
- **T15** (`Passw0rd`, 8 симв.): ожидалось `OK`, получено `LEN`.
- **T16** (`Abc123😀`, 8 `char`): ожидалось `CHAR`, получено `LEN` + `CHAR`.
- **T17** (`abcdefgh`, 8 симв.): ожидалось `UPPER` + `DIGIT`, получено `LEN` + `UPPER` + `DIGIT`.
- **T20** (`1bcdefgH`, 8 симв.): ожидалось `OK`, получено `LEN`.

Все 6 провалов — ровно пароли длиной 8 `char`. Сценарии с длиной 9–16 (T02, T08, T10, T14) и 7/17 (T03, T04) прошли. Это полностью согласуется с гипотезой о `len <= 8`.

## 2. Нарушенные требования

- **R02** — длина 8 ошибочно считается недопустимой (нижняя граница сдвинута).
- **R06** — для корректного пароля длиной 8 не выводится `OK` (T01, T15, T20).
- **R07** — код `LEN` выводится при длине 8, хотя нарушения длины нет (T01, T06, T15, T16, T17, T20).
- **R11** — для T06, T16, T17 выводится лишний код `LEN`, что нарушает состав кодов ошибок (порядок при этом сохраняется, но набор неверен).

R03, R04, R05, R08, R09, R10 в дефектной версии работают корректно; T05, T07, T08, T09, T10, T14, T18, T19 прошли.

## 3. Минимальное исправление (unified diff)

```diff
--- a/PasswordValidator.java
+++ b/PasswordValidator.java
@@ -37,7 +37,7 @@
 
         // R02, R07: длина 8..16 в единицах UTF-16 (String.length())
         int len = password.length();
-        if (len <= 8 || len > 16) {
+        if (len < 8 || len > 16) {
             out.append("LEN\n");
             hasError = true;
         }
```

Единственное изменение — `<=` → `<` в условии нижней границы. Верхняя граница (`> 16`) уже корректна: длина 16 допустима, 17 — нет. Никаких других изменений не требуется; рефакторинг не выполняется, формат вывода сохраняется, объём кода не меняется.
